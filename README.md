# LIVING MORPHOLOGIES

Emergent-network research instrument for Design 7. The interface walks a single architectural workflow:

**Typology → Archetype → Criteria → Descriptors → Physarum → 2D Section → 3D Model → Evaluation → Iteration**

Lobby, Workspace, and Gathering are the three typologies. Each holds five archetypes. Formal, Spatial, and Atmospheric ratings (Low / Medium / High) remain the precedent analysis; the center field is a visual Physarum simulation, not a scientific solver.

## Run the UI

```bash
npm install
npm run dev
```

Then open [http://127.0.0.1:43141](http://127.0.0.1:43141).

Production-style local serve:

```bash
npm run build
npm start
```

## Stack

Next.js, TypeScript, Tailwind. No extra services, database, or 3D engine.

## Skills

Cursor skill definitions live in `.cursor/skills/` and must not be overwritten when extending the app.
